# ATS Scoring Methodology

ResumeIQ's initial ATS-style score is a deterministic 0-100 completeness score. It is not a prediction of hiring outcomes and it does not compare a resume with a job role.

| Category | Maximum | Rule |
|---|---:|---|
| Skills | 40 | Five points for each detected, normalized skill; capped at 40. |
| Certifications | 20 | Ten points for each detected certification; capped at 20. |
| Projects | 25 | Thirteen points for each detected project entry; capped at 25. |
| Education | 15 | Fifteen points when an explicit Education section is detected. |

The dashboard shows the points, evidence-based rationale, and an improvement tip for each category. Work experience remains displayed in the extracted profile but is not weighted in this rubric. Role requirements, role matching, and skill-gap recommendations are intentionally deferred to later phases.
